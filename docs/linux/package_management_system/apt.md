# apt package manager

`apt` is the high-level Debian/Ubuntu package manager used to install, update, and remove packages.

## How to check available app version in apt?

```bash
apt-cache policy <package_name>
```

## Search for a package by name

```bash
apt-cache search <keyword>
```

## Show detailed info about a package

```bash
apt-cache show <package_name>
```
