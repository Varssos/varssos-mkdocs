# POSIX

[POSIX wikipedia](https://en.wikipedia.org/wiki/POSIX)

Portable Operating System Interface for UNIX — a family of standards that define a consistent API/CLI (shell, utilities, system calls) so software written for one POSIX-compliant OS can be ported to another with minimal changes. Linux, macOS and BSD are all largely POSIX-compliant, which is why most shell scripts and core utilities (`ls`, `grep`, `awk`, ...) behave the same across them.
