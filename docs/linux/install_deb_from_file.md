# Install deb packages from file

[Manual packages installation](https://help.ubuntu.com/kubuntu/desktopguide/C/manual-install.html)

Steps:

1. Download desired .deb package
2. Install .deb file in terminal:
```bash
sudo dpkg -i package_file.deb
```
3. If you want to remove:
```bash
sudo apt-get remove package_name
```
