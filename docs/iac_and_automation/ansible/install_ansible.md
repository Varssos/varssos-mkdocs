# Installing Ansible

[Complete tutorial on how to install Ansible](https://docs.ansible.com/ansible-core/devel/installation_guide/intro_installation.html#installation-guide)

The easiest way is to run:
```bash
python3 -m pip install --user ansible
sudo apt-get install sshpass
```

!!! warning
    In a production environment you should consider installing Ansible via a Python virtual environment to stay independent from the system Python version.
